# 📝 NeonJulia ⚡
- NeonJulia est une **mini‑webapp** néon servie par un `micro‑serveur HTTP en Julia`.

---

### 🚀 Lancer le projet
- Installe les dépendances et lance :
```bash
julia --project=. src/NeonJulia.jl
```

- Puis ouvre :
```http
http://localhost:8080
```

>dans ton navigateur.
